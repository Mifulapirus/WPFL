WPFLBroadcast graphics for OBS

Setup

Each graphic is a live web page. In OBS add a Browser source with the link below, Width 1920, Height 1080, and leave “Shutdown source when not visible” off so it stays connected. Everything updates on its own from the referee console; pages reload themselves after an update.

  • The fight bar has a transparent background: put it above the camera. Bracket and ranking have a dark background (full-screen scenes); add ?bg=transparent to put them over video, or ?bg=green for a chroma key.
  • Before event day they show the next scheduled event. Add ?demo=1 to the fight bar to see a fight run through every state (countdown, clock, KO count, winner) while you build the scenes.
