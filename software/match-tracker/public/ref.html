The record button on a robot (e.g. 2–1) opens its fight history right below it: Change… corrects a winner or method, Reset sends a fight back to the queue (fight it again or record it by hand). Byes can't be reset — delete the round instead.

Events

Draft → Publish (public as upcoming: countdown, info, robot cards) → Start event (live: fights, bracket, lights) → End event (saved to Past events). Robots and brackets can be set up at any stage; the event picker at the top chooses which event the Bracket and Robots tabs edit.
